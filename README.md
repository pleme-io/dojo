# dojo (道場) — the master testing vocabulary

The proving hall where every pleme-io testing **quality** is a composable typed
**facet**. A `(defsuite …)` carries many facets over one injected Environment; they
`gate_on` each other and `meet` into one `Veredito`, sealed by one attestation,
compiled to a `shigoto::Dag`, liftable to a Viggy `(defpromessa)`.

Facets (each hooks an unchanged engine): `(defcase)` omote shell-interface ·
`(defensaio)` ensaio architectural-trial · `(defparity)` sui differential ·
`(defperf-lever)` perf-seal honesty-gate · `(defprova)` tameshi/promessa attest ·
`(defproperty)` · `(deflaws)` · `(defmatrix)` · `(defcompose)` · `(defrebuild-probe)`.

dojo is a **composition index** — it owns only the thin border (`Veredito` /
`Outcome` / `Report` / `Evidence` / `DojoFacet`) + the operators; every facet engine
is kept and consumed.
